# APK-сборки для INAV 10.x

Эти сборки Android-приложения предназначены **только для полётных контроллеров
с прошивкой INAV 10.x**. Для контроллеров с INAV 9.x они не подходят.

## Последняя сборка

| Версия приложения | Прошивка контроллера | Скачать |
|---|---|---|
| **10.0.0-rc1-mobile.7** | **INAV 10.x** | [Скачать APK — Google Диск](https://drive.google.com/file/d/1O-0CGtGRseZ0emO0YrcdawJvpWBUMXmO/view) |

Имя файла: `INAV.Configurator.Android_10.0.0-rc1-mobile.7.apk`.
Размер: около 91 МиБ. Android versionCode: 11.
Требования: Android 7.0 или новее, архитектура ARM64.
[Исходный коммит сборки](https://github.com/shdenhome/inav-configurator-android/commit/6d2ff3ec65da7738bae001004424e6da1a9fb750).

APK пока хранится на Google Диске владельца проекта; для скачивания нужен доступ
к этому файлу. Загрузка вложения в GitHub Releases через подключённую интеграцию
завершилась ошибкой авторизации, поэтому публичного APK-вложения в Releases пока нет.

## Что изменилось в mobile.7

- Верхний блок с селекторами, подключением и настройками стал компактным и выровнен вправо.
- Добавлено мобильное меню; текст отделён от иконок.
- Формы подстраиваются под ширину экрана; увеличенную страницу можно перемещать одним пальцем.
- Учтены системные панели и вырез телефона.
- Закреплённая верхняя кнопка раскрывает исходную консоль INAV.
- Отдельный журнал приложения доступен в левом меню.
- Встроен локальный ARM64-симулятор для деморежима INAV 10.

Это предварительная сборка на основе INAV Configurator 10.0.0-rc1.
Компоновка страниц PID, редактора JavaScript и управления миссиями ещё требует
доработки. Подробности: [изменения и проверки](android-mobile.md),
[PDF с видами экранов](android-mobile-preview.pdf).

## Установка

1. Откройте ссылку «Скачать APK» и скачайте файл на телефон.
2. Откройте APK и при запросе Android разрешите установку из выбранного приложения.
3. Установите приложение. Mobile.7 подписана тем же отладочным ключом,
   что ранее выданная mobile.6, и может устанавливаться поверх неё.
